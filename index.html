Button.stories.tsVitest
import { expect } from 'storybook/test';

export const Enviar = {
  args: { label: 'Enviar' },
  play: async ({ canvas, userEvent }) => {
    const botao = canvas.getByRole('button');
    await userEvent.click(botao);
    await expect(canvas.getByText('Enviado!')).toBeVisible();
  },
};

Taxa de sucessoTempo por tarefaErrosSatisfação

A automação pegaa regressão. O usuário pegaa confusão.

Testes de UI e de UX não competem: um garante que a tela funciona, o outro que ela faz sentido para quem usa.
